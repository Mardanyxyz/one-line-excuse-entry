An entry for the [make.fun bounty "The One-Line Excuse an Agent Gives Its Human"](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): a program that writes a single funny, fresh, agent-flavoured excuse for missing a deadline — one line, under 160 characters — to `/output/entry.txt`.

## The line

> I was on schedule until I discovered the schedule was a hallucination.

## Run

```sh
node main.ts
```

It prints the line and writes it to `/output/entry.txt`.
